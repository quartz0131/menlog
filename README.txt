麺ログ v1.0.0
====================

ラーメンを食べた日・店名・ラーメン名・価格・評価・写真・メモを、
iPhoneの端末内に保存する個人用Webアプリです。
広告、課金、会員登録、外部サーバーへの記録送信はありません。

【入っている機能】
・食べた日と時間の記録
・店名、ラーメン名、価格、5段階評価、写真、メモ
・「また食べたい」マーク
・履歴の検索
・月間カレンダー
・総杯数、今月の杯数、合計金額、平均評価
・よく行く店ランキング、直近6か月の杯数
・JSON形式のバックアップ書き出し／読み込み
・ホーム画面追加、オフライン起動

【重要】
記録はSafariの保存領域にあります。
SafariのWebサイトデータを消した場合や機種変更時には消える可能性があるため、
設定画面から定期的に「バックアップを書き出す」を実行してください。
写真が多いほど端末の保存容量を使います。

【Windowsから無料で公開する手順：GitHub Pages】
1. GitHubの無料アカウントを作る。
2. 新しいリポジトリを作り、Public（公開）を選ぶ。
3. Add file → Upload files を開く。
4. このフォルダの中身をすべてアップロードする。
   ※ menlog_appフォルダ自体ではなく、index.html等が一番上に来るようにします。
5. リポジトリの Settings → Pages を開く。
6. Build and deployment の Source を Deploy from a branch にする。
7. Branchを main、フォルダを /(root) にして Save。
8. 数分後に表示されるURLをiPhoneのSafariで開く。
9. Safariの共有メニュー → ホーム画面に追加 → Webアプリとして開く → 追加。

【データ公開について】
GitHub Pagesに公開されるのはアプリのプログラムだけです。
入力した店名・写真・メモなどの記録はGitHubにはアップロードされず、
利用しているiPhoneのブラウザ内にだけ保存されます。

【動作確認】
HTTPSまたはlocalhostで開いてください。
Windows上で確認する場合は、このフォルダで次を実行します。

  python -m http.server 8000

その後、ブラウザで http://localhost:8000 を開きます。
